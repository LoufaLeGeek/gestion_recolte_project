# Gestion de recolte

## Description
Projet Laravel utilisant Livewire, Tailwind, DaisyUI Shadcn UI,et Oracle (Yajra).

## Prérequis
- PHP 8.2+
- Composer
- Node.js / npm
- Oracle XE 21c
- Oracle Instant Client 21 (basik and sdk)


## Installation locale

```bash
git clone <repo>
cd <repo>
cp .env.example .env
composer install
npm install
php artisan key:generate
npm run dev
php artisan serve
